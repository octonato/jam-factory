# AGENTS.md

## Glossary

`GLOSSARY.md` defines the terms of Jam Board and of the user workflow.

When a spec introduces a new term, or a change adds a new Jam Board concept, define it in `GLOSSARY.md` in the same change:

- Add it only when the term becomes part of the domain language. Skip terms used once, local names and plain English words.
- Skip factory internals, such as session files, review findings and agents.
- Put it in the section that fits its area, as a `**Term**: definition` paragraph.
- Keep the definition to one to three short sentences. State what the term is, not how to use it.
- When a spec changes the meaning of a term the glossary defines, update its entry.
